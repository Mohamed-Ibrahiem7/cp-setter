The first line contains a single integer $T$ ($1 \le T \le 10^4$) --- the number of test cases.

The first line of each test case contains a single integer $N$ ($1 \le N \le 2 \cdot 10^5$) --- the number of problem sets.

The second line contains $N$ integers $C_1, C_2, \ldots, C_N$ ($1 \le C_i \le 10^9$) --- the initial number of unsolved problems in each set.

The third line contains $N$ integers $V_1, V_2, \ldots, V_N$ ($1 \le V_i \le 10^9$) --- the number of points awarded for winning each set.

It is guaranteed that the sum of $N$ over all test cases does not exceed $2 \cdot 10^5$.
