The first line contains two integers $n$ and $m$ ($1 \le n, m \le 10^5$) --- the number of vertices and the number of edges, respectively.

The second line contains $n$ integers $a_1, a_2, \ldots, a_n$ ($0 \le a_i \le 10^9$) --- the values assigned to the vertices.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) --- the endpoints of an undirected edge.

The graph may contain self-loops and multiple edges between the same pair of vertices.
